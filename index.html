I am a penetration-testing specialist who learned the trade the structured way — the Hack The Box Academy Penetration Tester job-role path (28 modules, 23 assessments), from initial information gathering all the way to professional reporting. That methodology shows up in everything I build.

Right now I run two personal attack labs: an Active Directory lab for enterprise attack paths (enumeration, privilege escalation, lateral movement, pivoting) and a web application lab where I test authentication, authorization, BOLA, SQL injection and JWT weaknesses against a Python API I control.

My edge is that I can both test and build. I script workflows in Python and Bash, handle REST APIs and SQL, and document everything in a style a client or blue team can actually act on.
